# 휠웨이 (Wheelway)

휠체어 사용자를 위한 이동 정보 웹사이트의 초기 버전입니다. 네이버 지도와 자동차 경로, TAGO 저상버스 도착 정보, 배터리 잔여 거리 추정, 공공데이터 CSV 기반 충전소 검색을 제공합니다.

**안전 안내:** 자동차 경로는 휠체어 경로가 아닙니다. 보도·턱·경사·공사 정보가 없어 접근 가능한 경로나 도보 시간, 충전소 도착 시간을 제공하지 않습니다. 배터리 거리는 단순 추정치이고 충전소 운영시간은 실시간 이용 가능 여부가 아닙니다. 이동 전에 현장과 충전소에 확인하세요.

## 실행

Node.js 20 이상이 필요합니다. 별도의 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다. 키가 없으면 화면과 배터리 계산을 사용할 수 있지만 지도와 실시간 조회는 사용할 수 없습니다. 배포하려면 Node.js 서버를 실행할 수 있는 환경이 필요합니다.

## 실제 데이터 설정

서버 실행 환경에 다음 변수를 설정합니다. 비밀키는 소스 코드나 Git에 저장하지 마세요.

| 변수 | 설명 |
| --- | --- |
| `NAVER_CLIENT_ID` | 네이버 클라우드 Maps Application Client ID. 지도 SDK에도 공개됩니다. |
| `NAVER_CLIENT_SECRET` | 네이버 클라우드 Maps Application Client Secret. 서버에서만 사용합니다. |
| `DATA_GO_KR_KEY` | 공공데이터포털 일반 인증키 **디코딩** 값. TAGO 버스도착정보 서비스 이용 승인이 필요합니다. |
| `PORT` | 서버 포트. 기본값 3000 |

예를 들어 변수를 현재 셸에 설정한 뒤 `npm start`를 실행합니다. 네이버 클라우드 콘솔에서 **Dynamic Map, Geocoding, Directions 5**를 신청하고 웹 서비스 URL에 사용할 도메인(로컬 개발 시 `http://localhost:3000`)을 등록해야 합니다. API 사용량과 요금, 서비스별 허용 도메인 및 이용 약관을 확인하세요. 도로명 주소로 검색하며 주소가 여러 개면 첫 번째 결과를 사용합니다. 경로는 자동차 빠른길 기준입니다.

저상버스는 [TAGO 버스도착정보](https://www.data.go.kr/data/15098530/openapi.do)를 사용합니다. 이용자가 TAGO 도시코드와 정류소 ID를 입력해야 하며, 해당 도시의 서비스 제공 여부에 따라 결과가 없을 수 있습니다. 처음 100건에서 저상 차량만 표시합니다.

충전소는 [전국전동휠체어급속충전기 표준데이터](https://www.data.go.kr/tcs/dss/selectApiDataDetailView.do?publicDataPk=15034533)에서 내려받은 UTF-8 CSV를 화면에서 직접 불러옵니다. 최소 `시설명`, `위도`, `경도` 열이 필요합니다. 파일은 브라우저에서만 처리되며 출발지 기준 직선거리로 다섯 곳을 표시합니다. 공휴일을 포함한 운영시간과 전화번호는 CSV에 있는 경우 표시합니다. 데이터의 갱신일과 실제 운영 여부를 확인하세요.

## 확인

```sh
npm test
```

이 서비스는 API 키를 보관하는 서버에 인증이나 요청 제한을 제공하지 않습니다. 공개 서비스로 배포하기 전에 접근 제어, 요청 제한, 개인정보 및 위치정보 처리, 외부 API 약관과 요금에 대한 검토가 필요합니다.
